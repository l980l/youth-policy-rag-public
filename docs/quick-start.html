본인 API 키 2개만 준비하세요

AI 답변용 키와 정책 자료용 키가 각각 필요합니다.
설치와 실행은 받은 코드와 함께 Codex에 맡기면 됩니다.

01Gemini API 키

용도: AI 정책 탐색과 질문에 대한 답변 생성

Google AI Studio 열기 ↗
  1. Google 계정으로 로그인합니다.
  2. API 키 생성 메뉴에서 본인 프로젝트를 선택하거나 새로 만듭니다.
  3. 발급된 키를 프로젝트의 .env 파일에 있는 LLM_API_KEY= 뒤에 입력합니다.

프로젝트 선택·약관 동의 등이 필요할 수 있습니다. 이 코드는 Gemini 설정이므로 다른 제공자의 API 키만 넣어서는 동작하지 않습니다.

호출 한도와 요금은 본인 계정 기준입니다. 무료 한도도 무제한은 아닙니다. AI Studio에서 사용량과 결제 상태를 확인하세요.

02온통청년 API 키

용도: 공식 청년정책 자료 조회·수집

온통청년 발급 안내 열기 ↗
  1. 온통청년 홈페이지에 로그인합니다.
  2. 마이페이지 → 오픈(OPEN) API에서 인증키 발급을 신청합니다.
  3. 승인된 정책 API 키를 .env 파일의 YOUTH_API_KEY= 뒤에 입력합니다.

신청만 한 상태라면 조회가 안 될 수 있습니다. 승인 상태도 확인해 주세요.

.env에는 이렇게 입력합니다

받은 코드의 .env.example을 .env로 복사한 뒤, 두 줄만 본인 키로 채우세요. 기존 .env가 있으면 그 파일을 수정합니다.

LLM_API_KEY=본인의_Gemini_키
YOUTH_API_KEY=본인의_온통청년_키

나머지 설정은 샘플 그대로 두면 됩니다. GMS_KEY는 비워 둡니다.

키는 내 컴퓨터의 .env에만 저장하세요. 코드 공유자·채팅방·GitHub에 보내거나 올리지 마세요. 파일 이름은 .env.txt가 아니라 .env입니다.
